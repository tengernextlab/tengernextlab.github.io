# TengerNextLab вэб сайт

Next.js 15 + Tailwind CSS 4 дээр хийгдсэн компанийн танилцуулга сайт.

## Ажиллуулах

1. [Node.js LTS](https://nodejs.org) суулгана.
2. Төслийн хавтаст:

```bash
npm install
npm run dev
```

3. Хөтөч дээр http://localhost:3000 нээнэ.

## Засварлах

- Бүх текст, холбоо барих мэдээлэл: `lib/content.ts`
- Хэсгүүд: `components/` (Header, Hero, About, Services, Projects, Contact, Footer)
- Өнгө, фонт: `app/globals.css` дахь `@theme`

## Байршуулах

[Vercel](https://vercel.com) дээр GitHub repo-гоо холбоход автоматаар байршина.
